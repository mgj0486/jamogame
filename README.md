# 자모게임

한글 자모 5개 또는 6개로 이루어진 단어를 맞히는 안드로이드 게임.
워들처럼 자모가 정답에 들어 있으면 노란색, 자리까지 맞으면 초록색으로 표시한다.

| | |
|---|---|
| 입력 | 기본 자모 24개(자음 14 + 모음 10)로 된 두벌식 키보드 |
| 쌍자음·이중모음 | 기본 자모를 이어서 입력한다 (`ㄲ` = `ㄱㄱ`, `왜` = `ㅇㅗㅏㅣ`) |
| 시도 | 5회 |
| 저장 | 진행 중인 판과 설정을 기기에 남긴다 |

## 단어 데이터

출제 단어와 입력 검증 단어는 국립국어원 **한국어기초사전**에서 가져왔다.

- `app/src/main/assets/words_5.txt`, `words_6.txt` — 출제용 (명사, 어휘등급 초급·중급)
- `app/src/main/assets/valid_5.txt`, `valid_6.txt` — 입력 검증용 (품사·등급 무관)
- `tools/extract_words.py` — 사전 XML에서 위 목록을 뽑는 스크립트

> 이 저작물은 국립국어원 한국어기초사전을 이용하였으며,
> 크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 라이선스에 따라 이용할 수 있습니다.

## 입력 단어 검증

제출한 자모가 실제 단어인지 두 단계로 확인한다.

1. 내장 목록(`valid_*.txt`)에 있으면 바로 통과
2. 없으면 국립국어원 **우리말샘** 오픈 API 에 조회

API 인증키는 `local.properties` 에 둔다. 버전 관리에는 올라가지 않으며, 없으면 1단계만으로 동작한다.

```properties
opendictApiKey=발급받은_32자리_키
```

정답은 어떤 검사도 거치지 않고 통과시키고, 조회에 실패하면(네트워크 등) 막지 않는다.
